# 💰 Calculadora Lucrando Sem Risco

A **Calculadora Lucrando Sem Risco** é uma aplicação web desenvolvida para auxiliar usuários a otimizarem estratégias de apostas esportivas. A ferramenta permite calcular e gerenciar apostas com base em lógica matemática, identificando oportunidades de arbitragem (surebets) e maximizando o retorno sobre o investimento.

🌐 **Acesse aqui**: [www.lucrandosemrisco.com.br](http://www.lucrandosemrisco.com.br)

## ✨ Funcionalidades Principais

- **Calculadora de Arbitragem:** identifica oportunidades de lucro garantido entre diferentes casas de apostas.
- **Back e Lay:** suporte completo para apostas tradicionais e apostas contra.
- **Multi-resultados:** permite simulação com até 5 resultados possíveis.
- **Cálculo em Tempo Real:** resultados atualizados dinamicamente conforme o usuário edita os campos.
- **Gerenciamento de Comissões:** ajustes automáticos com base nas taxas das casas de apostas.
- **Interface Responsiva:** layout adaptável para desktop, tablet e celular.

## 🛠️ Tecnologias Utilizadas

- **React 19** – framework principal do front-end.
- **React Router** – navegação por rotas dentro da aplicação.
- **JavaScript ES6+** – lógica e cálculos matemáticos.
- **Context API** – gerenciamento de estado da aplicação.

## 🚀 Funcionalidades Técnicas Detalhadas

### 📐 Cálculo de Apostas
- Distribuição automática entre diferentes odds.
- Cálculo de stakes para apostas Lay.
- Ajuste preciso com comissões e bônus.

### 📊 Análise de Resultados
- ROI (Retorno sobre Investimento) automático.
- Simulação de lucro por cenário.
- Visualização da distribuição percentual dos valores.

### ⚙️ Personalização
- Definição da quantidade de resultados (2 a 5).
- Arredondamento customizável.
- Fixação de stake base para ajustes manuais.
